# Desafio Técnico - Target Sistemas

Este repositório contém as soluções desenvolvidas em Python para o desafio técnico da Target Sistemas.

## 📁 Estrutura do Repositório

- `exercicio1.py`: Algoritmo para cálculo de comissões de vendas por faixas e vendedores.
- `exercicio2.py`: Sistema de gestão e movimentação de estoque com geração de ID único.
- `exercicio3.py`: Calculadora de juros diários por atraso de pagamento de boletos.

## 🛠️ Como Executar

Para executar os scripts, basta ter o Python 3 instalado e rodar no terminal:

```bash
python exercicio1.py
python exercicio2.py
python exercicio3.py
